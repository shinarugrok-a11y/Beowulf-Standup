# Beowulf Standup

Public standup guide for **Beowulf**, a Steady Standup Ally on [Grok Bot](https://x.ai/bot).

One assistant that can plan, build, check, research, create, and operate.  
**You** stay the author. Beowulf is the clerk.

| File | Edition |
|------|---------|
| [BeowulfGB.pdf](./BeowulfGB.pdf) | Grok Bot black-and-white theme (public standup guide) |

Download the PDF, or ask an installed Beowulf to open / regenerate it after first-run setup.

## Install the bot

1. Install the **Beowulf** template from the Grok Bot share / marketplace card.
2. Complete first-run: name, “more human?”, constitution (`yes, that's me`), connectors.
3. Read this guide (or ask Beowulf for the standup PDF).

## Standing rules (short)

- Only a **typed yes** unlocks money, sending under your name, secrets, deletes, public posts, or purchases. Emoji is never that gate.
- Every real task gets an **ART** brief (Act as / Request / Terms) before labor.
- Chat is logistics; heavy work goes to files / CLI / GitHub.

## Further reading — Agentic Design Patterns

Beowulf is a **product standup**, not a patterns textbook. For the deeper pattern vocabulary (HITL, reflection, memory, guardrails, CLI agents, and more), start from:

- [evoiz/Agentic-Design-Patterns](https://github.com/evoiz/Agentic-Design-Patterns) — Antonio Gulli, *Agentic Design Patterns* (public repo + PDF)

Optional: after install, Beowulf can ask whether to use that repo as a learning base (and whether to look at forks). This standup repo stays separate so the guide and the book don’t get mixed.
